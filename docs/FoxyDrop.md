# FoxyDrop — передача файлов в FoxyXplorer по локальной сети

FoxyDrop — встроенный в FoxyXplorer HTTP-сервер для получения файлов с телефона, планшета или другого компьютера через обычный веб-браузер. Полученные файлы сохраняются в выбранную папку; автоматический импорт в FoxyXplorer не выполняется. Облачные сервисы и отдельное приложение на отправляющем устройстве не нужны.

## Быстрый старт

1. В FoxyXplorer откройте **Настройки** и выберите **Папка FoxyDrop** кнопкой `...`. Сохраните изменения кнопкой **Применить**. Выбранный каталог должен существовать и быть доступен для записи.
2. Нажмите кнопку **Загрузка** в верхней панели FoxyXplorer. Эта кнопка **только открывает** модальное окно и показывает состояние сервера.
3. Если отображается **Сервер остановлен**, нажмите **Start**. При успешном запуске появятся **Сервер запущен**, QR-код, URL и кнопка **Stop**.
4. На другом устройстве, имеющем сетевой доступ к компьютеру с FoxyXplorer, откройте указанный **HTTP-адрес** или отсканируйте QR-код.
5. На странице FoxyDrop нажмите **«Загрузить файл»** и выберите файл. Поддерживается загрузка только перечисленных на странице типов. Отправка начнётся автоматически.
6. После завершения браузер покажет сообщение **«Успешно загружено»**, **«Неподдерживаемый тип»** или **«Сбой загрузки»**. Примерно через три секунды сообщение исчезнет; можно отправить следующий файл.
7. Для остановки сервера откройте окно FoxyDrop и нажмите **Stop**.

**Важно:** закрытие *модального окна* не останавливает сервер, а кнопка в верхней панели не запускает его автоматически — даже после явной остановки через Stop. После перезапуска **самого приложения** сервер изначально остановлен и ожидает Start.

## Статусы, кнопка панели и выбор IP

- **Сервер остановлен** — сервер остановлен; доступна кнопка **Start**.
- **Запуск / Остановка** — запуск или остановка в процессе.
- **Сервер запущен** — HTTP-сервер слушает указанный IP и порт; доступны QR-код, адрес для копирования и **Остановить**.
- Кнопка **FoxyDrop** в верхней панели подсвечивается в работающем состоянии (в принятой цветовой схеме — оранжевым `#FF6600`, как активная кнопка Grid). При остановленном сервере подсветки нет.
- Приложение предлагает локальные IPv4-адреса, в том числе адреса разных сетевых интерфейсов. При наличии нескольких адресов можно выбрать нужный в окне FoxyDrop. Во время работы смена IP приводит к перезапуску сервера и обновлению URL и QR-кода.

Сначала FoxyDrop пытается занять **TCP-порт 8070** на выбранном IP. Если порт занят, операционная система автоматически выделяет свободный. Поэтому использовать нужно **фактический URL из модального окна**, например `http://192.168.0.3:8070` или `http://192.168.0.3:49152`.

Адрес `Server Running` показывает, что сервер запущен, **но сам по себе не означает**, что входящие подключения разрешены брандмауэром или сетью.

## Допустимые файлы и правила сохранения

| Параметр                            | Поведение                                                       |
| ----------------------------------- | --------------------------------------------------------------- |
| Разрешённые расширения              | `.gpx`, `.ms`, `.plt`, `.kml`, `.wpt`                           |
| Регистр расширения                  | Не учитывается: `.GPX` тоже допустим                            |
| Максимальный размер                 | **100 МиБ** на файл                                             |
| Выбор файла                         | Один файл за одну операцию браузера                             |
| Одновременные загрузки              | Не более двух                                                   |
| Место сохранения                    | Папка FoxyDrop из настроек                                      |
| Совпадение имён                     | Автоматическая нумерация; существующий файл не перезаписывается |
| Автоматический импорт в FoxyXplorer | Нет                                                             |

Например, при повторных загрузках `track.gpx` будут созданы `track.gpx`, `track (1).gpx`, `track (2).gpx` и т. д. Имена, присланные браузером, очищаются от компонентов пути и недопустимых символов.

Временная запись выполняется потоково; при неудачной передаче неполный файл удаляется. Для окончательного сохранения без перезаписи используются **жёсткие ссылки (hard links)**. На файловых системах, не поддерживающих жёсткие ссылки, запись может завершиться сообщением «Сбой загрузки». Это важно, например, при выборе папки на некоторых съёмных носителях FAT/exFAT. Для максимальной совместимости предпочтительны обычные каталоги на ext4 (Linux) или NTFS (Windows).

**Примечание:** проверяется расширение файла, а не соответствие внутреннего содержимого стандарту GPX/KML и т. п. Допустимое расширение не означает, что файл безопасен или корректен.

## Конфигурация

Путь к выбранному каталогу сохраняется в пользовательском `config.json` через **Settings → Apply** и восстанавливается при следующем запуске FoxyXplorer. Соответствующие поля:

```json
{
  "drop_folder": "/home/user/Downloads/FoxyDrop",
  "drop_port": 8070
}
```

Это **фрагмент** конфигурации, а не полный пример файла: остальные настройки FoxyXplorer необходимо сохранить. Значение `drop_port` — предпочтительный порт, а не гарантия, что сервер использует именно его. Настройки брандмауэра FoxyXplorer **не изменяет**.

## Доступ по сети и ответственность пользователя

FoxyDrop работает по **HTTP без HTTPS и без авторизации**. Любое устройство, которое может подключиться к выбранному IP и порту, потенциально может отправлять разрешённые файлы. Используйте сервер **только в доверенной локальной сети**.

- Не пробрасывайте порт FoxyDrop через маршрутизатор в интернет и не открывайте доступ из недоверенных сетей.
- Не отключайте брандмауэр целиком ради FoxyDrop.
- Создавайте минимально необходимые разрешения: входящий **TCP** только от нужной локальной подсети или к нужному приложению.
- **Все изменения правил выполняются пользователем самостоятельно и под его ответственность.** FoxyXplorer не запрашивает административных прав ради FoxyDrop и не меняет правила автоматически.
- В корпоративной или управляемой сети сначала согласуйте изменения с администратором.

### Linux: UFW

Если соединение блокируется, в журнале может появиться запись вида:

```text
[UFW BLOCK] IN=enp24s0 SRC=192.168.0.187 DST=192.168.0.3 PROTO=TCP DPT=8070
```

Для **этих конкретных примерных адресов** можно разрешить входящие TCP-подключения только на порт FoxyDrop:

```bash
sudo ufw allow in on enp24s0 from 192.168.0.0/24 to 192.168.0.3 port 8070 proto tcp
sudo ufw status numbered
```

Замените интерфейс `enp24s0`, подсеть `192.168.0.0/24`, IP компьютера `192.168.0.3` и порт `8070` на ваши фактические значения. Если FoxyDrop выбрал резервный порт, в разрешении нужен именно он. При изменении адреса или порта правило может потребовать обновления.

Чтобы удалить конкретное правило, посмотрите его номер через `sudo ufw status numbered` и выполните `sudo ufw delete НОМЕР` (заменив `НОМЕР` числом из списка). Не используйте широкое правило `sudo ufw allow from 192.168.0.0/24`: оно разрешает подключения из этой подсети **на все порты**, а не только к FoxyDrop.

Если используется не UFW, а firewalld, nftables или другое решение, настройте эквивалентное узкое правило средствами своего брандмауэра.

### Windows: Microsoft Defender Firewall

В Windows рекомендуется **разрешать входящий TCP-трафик конкретному исполняемому файлу**, а не открывать порт для всех программ: FoxyDrop может перейти с 8070 на свободный порт.

Если Windows предлагает разрешить сетевой доступ программе, разрешайте его только для **частных (Private)** доверенных сетей. При отсутствии запроса или блокировке подключения можно создать правило вручную:

1. Нажмите **Win + R**, введите `wf.msc` и нажмите Enter.
2. Откройте **Правила для входящих подключений → Создать правило**.
3. Выберите тип **Настраиваемое (Custom)**.
4. В разделе **Программа** укажите фактический путь к исполняемому файлу FoxyXplorer (например, `foxyXplorer.exe`).
5. В разделе **Протоколы и порты** укажите **TCP**. Если порт может выбираться автоматически, не фиксируйте номер локального порта.
6. В разделе **Область (Scope)** ограничьте **удалённые IP-адреса** вашей доверенной локальной подсетью, например `192.168.0.0/24`.
7. Выберите **Разрешить подключение**, затем только профиль **Частный (Private)**.
8. Назовите правило, например **FoxyDrop LAN Upload**.

Для опытных пользователей пример PowerShell **с правами администратора**:

```powershell
New-NetFirewallRule `
  -DisplayName "FoxyDrop LAN Upload" `
  -Direction Inbound `
  -Action Allow `
  -Program "C:\Path\To\foxyXplorer.exe" `
  -Protocol TCP `
  -Profile Private `
  -RemoteAddress 192.168.0.0/24
```

**Обязательно замените** путь к программе и подсеть. Указанное правило не привязано к фиксированному порту, но действует только для выбранного приложения и профиля сети. Если `.exe` переместили, обновите правило. Для удаления созданного правила:

```powershell
Remove-NetFirewallRule -DisplayName "FoxyDrop LAN Upload"
```

Если установлен сторонний брандмауэр (ESET, Kaspersky, Bitdefender и др.), используйте его собственный интерфейс. Универсальные параметры: **входящий TCP**, **приложение FoxyXplorer**, **доверенная подсеть**, действие **Allow**; если правило можно сделать только по порту — задайте фактический порт из URL. Учтите, что корпоративные политики могут запрещать изменения.

Официальные сведения: [Microsoft — риски открытия портов и разрешения приложений](https://support.microsoft.com/ru-ru/windows/security/firewall/risks-of-allowing-apps-through-windows-firewall), [Microsoft Learn — расширенные правила](https://learn.microsoft.com/en-us/windows/security/operating-system-security/network-security/windows-firewall/configure).

### macOS — предварительная инструкция, не проверена на FoxyDrop

Проверка работы FoxyDrop на macOS **отложена**. Если в дальнейшем входящие подключения будут блокироваться штатным брандмауэром, проверьте **System Settings → Network → Firewall → Options** и наличие разрешения на входящие подключения для приложения FoxyXplorer. Названия и расположение пунктов могут отличаться между версиями macOS. Сторонние средства сетевой защиты настраиваются отдельно.

См. [Apple Support — Block connections to your Mac with a firewall](https://support.apple.com/en-ie/guide/mac-help/mh34041/mac).

## Если подключение не работает

| Симптом                                         | Что проверить                                                                                                               |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Server Down** или ошибка Start                | Выбрана ли папка FoxyDrop, существует ли она и разрешена ли запись; доступен ли выбранный IPv4-интерфейс                    |
| **Server Running**, но браузер не открывает URL | IP и **фактический порт**, доступность устройств друг для друга, брандмауэр, VPN, изоляцию клиентов Wi-Fi или гостевую сеть |
| QR-код ведёт по недоступному адресу             | Выберите другой IP в окне FoxyDrop и повторно отсканируйте QR-код                                                           |
| Браузер показывает **«Неподдерживаемый тип»**   | Расширение должно быть `.gpx`, `.ms`, `.plt`, `.kml` или `.wpt`                                                             |
| Браузер показывает **«Сбой загрузки»**          | Размер файла (до 100 МиБ), права на запись, свободное место, тип файловой системы, состояние сети                           |
| Файл передан, но не появился в списке треков    | Это ожидаемо: FoxyDrop **сохраняет файл на диск**, но не импортирует его в FoxyXplorer                                      |

Для проверки адреса сначала откройте URL **на самом компьютере** с запущенным сервером, затем — с другого устройства. Не заменяйте `http://` на `https://`: HTTPS в FoxyDrop не предусмотрен.

## Совместимость и дальнейшая проверка

| Платформа   | Статус                                                                          |
| ----------- | ------------------------------------------------------------------------------- |
| **Linux**   | Проверено в работе, включая настройку UFW                                       |
| **Windows** | Проверено в работе; при необходимости правила брандмауэра настраиваются вручную |
| **macOS**   | **Не проверено**. Требуется отдельный практический тест                         |
